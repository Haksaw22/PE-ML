## Line G — G2/G3 + separability certificate (block-diagonal excitation)

**JUDGE: novelty bar = REJECT · instrument bar = REVISE** (confidence: high)

### Judge rationale
Two of the charges are direct algebraic derivations from the note's own definitions, independently re-checked here, not the analogy-to-precedent reasoning the calibration note tells us to discount. (1) M*_static = Σφφ^{-1/2} Σφy Σyy^{-1} Σyφ Σφφ^{-1/2} is a congruence transform (by the invertible Σφφ^{-1/2}) of Σφy Σyy^{-1} Σyφ, whose rank equals rank(Σφy) ≤ min(dim φ, dim y) since Σyy^{-1} is full-rank square — standard CCA algebra (Hotelling 1936). For scalar y, rank ≤ 1, so at most one projector Πᵢ can have λ_min(ΠᵢM*Πᵢ)>0; the k≥2 static-face certificate is unsatisfiable by construction, and this hits the note's own named flagship cases (football corollary's scalar reward; the Garg-style scalar-regression benchmark named in prediction #3). Conceded by the defense without qualification. (2) M*_seq expands to E[φtφt^T] − γE[φtφt+1^T] − γE[φt+1φt^T] + γ²E[φt+1φt+1^T] — a fixed linear combination of the lag-0 block, the lag-1 block and its transpose, and a shifted lag-0 block — not 'the lag-1 slice of a block-Hankel' as claimed. Also conceded. This directly kills the specific 'same shifted-moment operator' unification claim (prediction #2), which the prior-art investigator's own residual_novelty analysis flags as the strongest candidate for what is genuinely new here (vs. classical CCA/Fisher-orthogonality subsumption threats on the static face alone). With both the static-face object and the cross-face unification independently and mathematically dead, what remains (per the defense's own 'strongest_surviving_claim') is a block-diagonal TD-residual Gram certifying per-block LSTD/TD(0) identifiability — explicitly tied to and not distinguished from established TD-Gram convergence-rate theory (Bhandari-Russo-Singal 2018; Srikant-Ying 2019), whose per-block form is a natural blockwise application, not a new law. The quantitative O(κ²ρ²) scaling law (claim 5) is, per charge 5 (whose core math the defense concedes is correct), generic second-order Neumann/Taylor perturbation calculus for ANY block/off-block PSD split under a quadratic loss, already catalogued for a different purpose in K-FAC's block-diagonal-Fisher error bounds, and the underlying qualitative fact (block-diagonal Fisher ⟺ information-orthogonal, separately-estimable parameters) is textbook (Cox & Reid 1987) and independently rediscovered in near-identical form by contemporaneous 2023-2026 disentanglement work (Lachapelle et al.; Mechanistic Independence arXiv 2509.22196; Ortiz-Jimenez et al. + arXiv 2604.17078). No new object or law survives that is not either (a) mathematically broken on the note's own terms, or (b) a relabeling of already-established criteria into excitation vocabulary. — On the instrument bar, a narrower object does survive charge 1's specific mechanism and is not hit by charge 4: the sequential/RL TD-residual-Gram certificate, restricted to prong (a) of the non-vacuousness repair only (an externally pre-given architectural partition — prong (b)'s eigengap route is conceded circular, echoing the already-validated M_S/A1 circularity finding, which the calibration note's audit of Q1 confirms held up under re-derivation). This object is the right kind of thing for the phenomenon (tied to real TD convergence theory, not a wrong-object auto-Gram), and it comes with a genuinely falsifiable, non-over-determined two-sided design against the single nearest baselines (predictions 5: eigenoptions splits at a topological bottleneck where the excitation certificate should not, and vice versa on a fully-connected/separable-reward environment; same two-sided structure vs. DIAYN). That design is a real instrument-bar candidate. But the filed candidate line is 'G2/G3 + separability certificate,' and both G2 (static face, killed by charge 1) and G3 (the discovery objective, min_φ Σ −log λ_min(ΠᵢM*Πᵢ) + β Σ‖ΠᵢM*Πⱼ‖²) fail the instrument bar as filed: G3's training objective directly optimizes for its own success criterion over a flexible modular φ, which guarantees a low-ρ, high-αᵢ split exists and will be found regardless of whether it tracks real task/skill structure (charge 2, essentially unrebutted for the learned-φ case — the defense only rescues the fixed-partition detection use, not the G3 discovery use). That is a sign-over-determination failure by the bar's own explicit criterion. Kill criterion #1 (quadratic scaling) is likewise sign-over-determined per charge 5 and should not be presented as discriminating evidence. Net: as filed, G2 and G3 both fail the instrument bar; a narrow non-circular sequential-only detection certificate survives but is not what was submitted and needs to be explicitly re-scoped and re-filed.

### Developer formulation
**Object definition:** Fix a feature map φ:X→ℝ^d (frozen for few-shot; the value/policy feature for RL). Define the task-coupling operator M* (replacing the retired static Gram M_S) via one of two faces:

STATIC FACE (G2): with Σ_φφ=E[φφ^T], Σ_φy=E[φy^T], Σ_yy=E[yy^T] (y = output/target), define
  M*_static := Σ_φφ^{-1/2} Σ_φy Σ_yy^{-1} Σ_yφ Σ_φφ^{-1/2}  (d×d, PSD, eigenvalues in [0,1] = squared canonical correlations; eigenvectors in whitened-φ coordinates = the CCA / reduced-rank-regression directions). Requires Σ_φφ, Σ_yy invertible or restricted to their supports.

SEQUENTIAL FACE (G1/G6): with φ_t=φ(s_t,a_t), γ the discount, define
  M*_seq := E[(φ_t - γφ_{t+1})(φ_t - γφ_{t+1})^T]  (PSD; this is the Gram version of the LSTD/TD(0) operator A=E[φ_t(φ_t-γφ_{t+1})^T] whose (semi)definiteness governs TD convergence; equivalently the lag-1 block of a block-Hankel matrix built from (φ_t, r_t) sequences, so it is a genuine restriction of the block-Hankel realization-theory object to the value-relevant subsequence, not an independent construction).

A MODE DECOMPOSITION is a set of orthogonal projectors {Π_1,...,Π_k}, ΣΠ_i=I, WHOSE DEFINITION IS EXTERNAL TO M* -- i.e. fixed by (a) a pre-given architectural/coordinate partition of φ (disjoint sub-network outputs or disjoint action/state-subspace blocks), or (b) a model-selection rule requiring an explicit eigenvalue-clustering gap in spec(M*) (or a Hankel singular-value gap) with k≪d. [This external-basis requirement is a repair not present in the source note; without it, block-diagonality in M*'s own eigenbasis is a vacuous restatement of the spectral theorem, reproducing exactly the circularity defect that got M_S REVISE'd in G1.]

The modes are INDEPENDENT AT LEVEL α w.r.t. M* if Π_iM*Π_j=0 (i≠j) and λ_min(Π_iM*Π_i)≥α_i>0 ∀i. The APPROXIMATE version replaces the first condition with a bound on off-block mass ρ := Σ_{i≠j}‖Π_iM*Π_j‖ / ‖M*‖.

**Core claims:**
- Separability certificate (corrected): given a task-coupling operator M* (defined below, NOT the static auto-Gram M_S) and an orthogonal partition {Π_i}, Σ_iΠ_i=I, fixed independently of M* (see non-vacuousness clause), the modes are independent at level α iff Π_iM*Π_j=0 (i≠j) and λ_min(Π_iM*Π_i)≥α_i>0; then each block is separately identifiable, θ*=Σθ_i*, and (football corollary) max Σreward = Σ per-skill local optima EXACTLY when off-block mass ρ=0.
- Operator choice, static face (G2): M*_static = Σ_φφ^{-1/2} Σ_φy Σ_yy^{-1} Σ_yφ Σ_φφ^{-1/2} (whitened input-output cross-covariance / CCA operator; eigenvalues = squared canonical correlations, eigenvectors = reduced-rank-regression directions). This is categorically different from M_S = Σ_φφ (auto-Gram): M_S measures only input geometry and was shown (A1 gate) to be the wrong object because separability/estimator behavior is a statement about the φ→y MAP, not about φ's internal correlation structure, and because P built from M_S was circular.
- Operator choice, sequential face (G1/G6): M*_seq = E[(φ_t-γφ_{t+1})(φ_t-γφ_{t+1})^T], the Gram of TD-residual features (equivalently the symmetrized negative of the LSTD/TD(0) operator A=E[φ_t(φ_t-γφ_{t+1})^T]; equivalently the lag-1 slice of a block-Hankel built from (φ_t, r_t) sequences). This survives the M_S critique for the same reason M*_static does: it is tied to the actual operator (Bellman backup) whose fixed point defines the estimand, not to a state-occupancy auto-Gram, and it is a known load-bearing object in TD convergence theory (Bhandari-Russo-Singal 2018; Srikant-Ying 2019), giving it independent legitimacy beyond this program.
- Non-vacuousness repair (new, not in source note): any symmetric M* is trivially block-diagonal in its own eigenbasis (k=d, 1-dim blocks), so 'M* block-diagonalizes' is vacuous unless {Π_i} is fixed by something external to M* -- either (a) a pre-given architectural/coordinate partition (e.g. disjoint sub-network outputs, disjoint action-subspace blocks) that M* is TESTED against, or (b) a model-selection procedure requiring an explicit spectral GAP (eigenvalue clustering of M*, or Hankel singular-value gap) with k << d fixed by that gap, not by the eigenbasis alone. Absent this clause, the certificate and the G3 objective are not falsifiable claims about representations, they are restatements of the spectral theorem.
- Approximate/perturbation version: writing M* = D + E (D = block-diagonal part, E = off-block, ||E||≤ρ||M*||), for a quadratic/linear-in-features objective (RRR, LSTD -- the natural regime for M*), θ*=(D+E)^{-1}b, θ^sep=D^{-1}b, and by Neumann expansion (valid for ρ<α_min/||M*||): excess loss L(θ^sep)-L(θ*) = O(κ²ρ²) with κ=||M*||/α_min the block condition number -- a specific QUADRATIC scaling law, not merely 'monotone in ρ' as the source note states. Football condition is the ρ=0 special case, hence an exact corollary rather than a metaphor -- but only within this quadratic-loss scope (RRR/LSTD exactly; deep nonlinear RL only via local Gauss-Newton/NTK linearization, an explicit scope limit).
- G3 (representation learning) under corrected M*: min_φ Σ_i -log λ_min(Π_iM*(φ)Π_i) + β Σ_{i≠j}||Π_iM*(φ)Π_j||²_F, where {Π_i} are constrained to select disjoint coordinate blocks of a modular φ=[φ_1,...,φ_k] (architectural constraint enforcing the non-vacuousness clause), and M*(φ) is the cross-covariance operator (static) or TD-residual Gram (sequential) evaluated on the learned φ.
- Novelty wedge vs. DIAYN and eigenoptions is falsifiable in BOTH directions via two constructed environments: (i) topological bottleneck with unimodal/undifferentiated reward across it -- eigenoptions splits (Laplacian sees the bottleneck), excitation certificate does not (TD-Gram has no block boundary there); (ii) fully-connected state graph with two additively-separable reward channels -- eigenoptions has no structure to exploit and fails to split, excitation certificate splits cleanly (TD-Gram block-diagonalizes on the reward channels). DIAYN analog: two behaviorally-distinguishable-but-output-equivalent modes (DIAYN splits via I(S;Z), excitation certificate does not, no cross-covariance to output) vs. two behaviorally-similar/state-overlapping regions with different value contributions (DIAYN lumps, excitation certificate splits via TD-Gram).

**Falsifiable predictions:**
- Excess-loss scaling: in the RRR/LSTD (quadratic-objective) regime, plotting L(θ^sep)-L(θ*) against measured ρ on synthetic multi-skill tasks with known ground-truth block structure yields a slope-2 log-log fit (gap ∝ κ²ρ², not merely monotone), valid for ρ < α_min/‖M*‖; outside that regime the Neumann approximation should visibly break down (super-quadratic growth), which is itself a testable transition.
- Static/sequential unification: on a task with both a static (frozen-φ, in-context) and sequential (rollout) instantiation of the same skills, the top eigenvectors of M*_static (CCA directions) and the mode-partition recovered from M*_seq's spectral clustering should agree up to rotation within blocks -- i.e., M*_seq's lag-1-Hankel identity with M*_static's lag-0 cross-covariance should produce the SAME block partition, not merely analogous ones.
- G2 few-shot: CCA/RRR-selected demo directions (top-k canonical directions of M*_static, k set by the eigengap) predict which of several superposed sub-tasks are separately identifiable, and beat similarity/DPP shot-selection at equal shot budget on a Garg-style 2-3 task superposition benchmark.
- RL sample efficiency: per-mode excitation driving λ_min(Π_iM*_seqΠ_i)≥α_i on a compositional control task (e.g. reach+grasp with architecturally pre-specified action-subspace blocks) reaches per-skill identifiability with fewer environment steps than entropy exploration, and self-terminates per block once α_i is met.
- Falsifiable divergence from eigenoptions: in a topological-bottleneck / undifferentiated-reward environment, eigenoptions produces a skill boundary at the bottleneck while the excitation certificate (M*_seq) does not (ρ across the bottleneck stays near 0's complement -- i.e., no block split predicted there); in a fully-connected / additively-separable-reward environment, the reverse holds (eigenoptions fails to split, excitation certificate splits cleanly on the reward channels). Both must be observed for the novelty wedge to survive.
- Falsifiable divergence from DIAYN: in an environment with two state-distinguishable but output/value-equivalent behavior modes, DIAYN (I(S;Z) maximization) splits them into separate skills while M* shows no cross-block excitation to exploit (single block); in an environment with two state-overlapping but value-divergent regions, DIAYN lumps them while M*_seq splits them. Both must be observed.

**Kill criteria:**
- If the excess-loss-vs-ρ relationship on synthetic quadratic-objective tasks is not consistent with a slope-2 (quadratic) fit within the Neumann-valid regime (ρ<α_min/‖M*‖) -- a merely-monotone-but-non-quadratic relation falsifies the specific derived perturbation bound even though it would have passed the source note's weaker 'monotone in ρ' criterion.
- If M*_static's canonical directions and M*_seq's spectral-cluster partition do NOT agree (up to rotation) on a task instantiated both statically and sequentially -- kills the 'one object, two shifts' unification claim, demoting G1 and G2/G6 back to two unrelated certificates.
- If, in the two constructed diverging environments (bottleneck/undifferentiated-reward and fully-connected/separable-reward), the excitation-based decomposition does NOT diverge from eigenoptions in the predicted (opposite) directions -- the DIAYN/eigenoption novelty wedge is dead, per the source note's own kill criterion #4, now made concrete and two-sided rather than a single vague comparison.
- If real (non-synthetic) M* operators from trained models are spectrally diffuse with no clean eigenvalue/Hankel-singular-value gap for any k≪d -- the external-basis / model-selection route to non-vacuousness fails operationally, and G3's discovery objective has no principled stopping point (sharpens the source note's failure mode #3 into a specific spectral-gap test rather than a general worry).
- If M*_static (whitened cross-covariance/CCA operator) turns out to reduce, in the cases actually tested, to a monotone rescaling of the retired M_S (auto-Gram) -- e.g. because Σ_φy is dominated by Σ_φφ in the relevant regime -- then the 'corrected operator' is not actually a different object and the G1 repair fails on its own terms; this must be checked with an explicit counterexample/derivation, not assumed.
- If the architectural partition {Π_i} used in G3 experiments cannot be chosen blind to ground-truth skill identity (i.e., if only a partition designed with the answer already known produces the predicted block-diagonality) -- the certificate becomes unfalsifiable in practice even though well-defined in theory.

**Open risks:**
- Prior-art overlap on the operator choice itself: PE-style conditions on TD-Gram/LSTD operators for convergence RATE are already established (Bhandari, Russo & Singal 2018; Srikant & Ying 2019; Tsitsiklis & Van Roy 1997 for the underlying A-matrix stability condition). The novelty must rest entirely on the BLOCK-DIAGONAL/separability layer and the static-sequential unification, not on 'TD-Gram is the right excitation object for RL', which is not new.
- Prior-art overlap on the football corollary / additive decomposition: Hybrid Reward Architecture (Van Seijen et al. 2017) and successor features / generalized policy improvement (Barreto et al. 2017) already decompose value/reward into additive, separately-learnable components under linear feature combination; factored-MDP structure learning (Kearns-Koller; Guestrin et al.) already formalizes when a task's dynamics/reward factor across variable blocks. A gate reviewer will likely find G1's football corollary close to already-known results; the differentiator (excitation/identifiability certificate with a quantitative ρ-to-gap bound, discovered via CCA/TD-Gram spectral structure rather than assumed factorization) needs to be argued explicitly against these, not just against DIAYN/eigenoptions.
- The static/sequential 'one object, two shifts' claim (M*_seq's lag-1-Hankel slice = M*_static's lag-0 cross-covariance) is asserted here as a structural analogy but not proven as an identity; until a lemma establishes the precise sense in which they are restrictions of a common block-Hankel/moment object, the 'unification' claim is a conjecture and the theory should be scoped as two related-but-separate certificates pending that proof.
- The quadratic excess-loss bound (gap = O(κ²ρ²)) is derived strictly for linear-in-features, quadratic-loss settings (RRR, LSTD/linear-TD exactly satisfy this); extending the football corollary to deep nonlinear policies/value functions requires a local Gauss-Newton/NTK linearization assumption that is not established and may not hold far from a local optimum -- this is a real scope limitation, not a detail, since the source note's prediction #3 (RL sample efficiency on deep-network compositional control) implicitly needs it.
- The non-vacuousness repair (external-basis / eigengap requirement) is a genuine addition to the source note not present in v0.1; it resolves the most obvious 'well-defined but vacuous' gate objection (block-diagonality in one's own eigenbasis is trivial) but introduces a new burden -- justifying that the chosen architectural partition or eigengap criterion is not itself circular with respect to the ground-truth skills being tested for. The source note's own failure mode #4 ('is the discovered decomposition the task's or the model's?') is exactly this risk and remains open.
- The overlap/soft-assignment case (source note failure mode #2: running∩kicking as shared components) is not handled by the exact block-diagonal-plus-perturbation theory developed here; a block-diagonal-plus-low-rank generalization of M* and its own perturbation bound has not been derived, so the certificate as stated only covers hard partitions.

### Prior art
**Nearest neighbors:**
- Lachapelle et al. 2023 (Additive Decoders for Latent Variables Identification and Cartesian-Product Extrapolation, NeurIPS) — establishes that if the true (and learned) decoder is ADDITIVE across latent blocks, the blocks are identifiable up to permutation/block-invertible transform, and additivity also licenses recombination into novel (Cartesian-product) compositions never seen in training — distance: close — this is the direct ancestor of the note's static-face claim (1) 'each skill separately identifiable' and a version of the 'skills recombine' story, proved WITHOUT excitation/Fisher/PE vocabulary; it does not touch the sequential/RL Hankel face, does not phrase the condition as a PE-rate (α-quantified) certificate, and has no reward-decomposition/optimization claim, but the core static-face identifiability mathematics is already there.
- Anonymous/'Mechanistic Independence: A Principle for Identifiable Disentangled Representations' (arXiv 2509.22196, Sep 2025) — proves that when a nonlinear generator's Jacobian is block-orthogonal across latent factors (Type-D 'disjoint' independence: D_i g · D_j g = 0), the latent blocks are identifiable up to block-wise invertible transforms and permutations, with NO statistical independence assumption — distance: close — Jacobian block-orthogonality is, under a Gauss–Newton/Gaussian-noise reading, algebraically the same object as Fisher/excitation-matrix block-diagonality (M ≈ J^T J), so this is essentially the note's separability-theorem claim (1) proved in mechanism/Jacobian language rather than excitation/Fisher language; it stays in the static representation-learning setting only — no RL/Hankel unification, no per-block PE-rate requirement, no optimization/reward-decomposition claim, no discovery-training objective phrased as minimizing off-block Gram mass.
- Ortiz-Jimenez, Favero & Frossard 2023 (Task Arithmetic in the Tangent Space, NeurIPS Oral) + follow-up 'Understanding and Enforcing Weight Disentanglement in Task Arithmetic' (arXiv 2604.17078) — establishes 'weight disentanglement': directions in (tangent-space/NTK-linearized) weight space correspond to localized, non-interfering regions of function space, empirically and via an NTK-Jacobian orthogonality lemma (τ_j^T J(x)=0 on task t's domain), and the follow-up proves Task-Feature-Specialization (disjoint feature use) ⟹ Weight-Vector-Orthogonality as the mechanism — distance: close — this is structurally claims (1)+(2) of the note's separability theorem ('cross-block coupling causes interference; orthogonality ⟹ additive task-vector combination ≈ θ*=Σθ_i*') already demonstrated for the specific case of fine-tuning task vectors, using an NTK/Jacobian-Gram object rather than a general excitation matrix; it does not generalize to few-shot ICL demo/attention routing, does not touch RL/Hankel, and does not propose a training objective that explicitly minimizes off-block excitation mass as a discovery procedure.
- Fifty, Amid, Zhao, Yu, Anil & Finn 2021 (TAG: Efficiently Identifying Task Groupings, NeurIPS) — establishes an EMPIRICAL, dynamic 'inter-task affinity' measured via lookahead-gradient-loss changes during joint training, used to greedily partition tasks into branches that should train together — distance: medium — same overarching problem (which tasks/skills don't trade off) but a fundamentally different object: an empirical, training-time proxy rather than an algebraic block-diagonal-excitation/Fisher certificate, no identifiability proof, no PE-rate quantification, no connection to few-shot/RL-Hankel; the seed list's 'close threat' framing is only half right — it is close in TERRITORY (predicting task groupings/separability) but not in OBJECT (heuristic loss-affinity vs. algebraic excitation-Gram certificate).
- Standley, Zamir, Chen, Guibas, Malik & Savarese 2020 (Which Tasks Should Be Trained Together in Multi-Task Neural Networks?) — same empirical task-grouping combinatorial-search paradigm as Fifty et al., using measured transfer/performance rather than any algebraic Fisher/excitation structure — distance: medium — same reasons as Fifty et al.
- Yu, Kumar, Gupta, Levine, Hausman & Finn 2020 (PCGrad) and its many 2023-2025 gradient-surgery descendants (CAGrad, GDOD, sparse-training conflict mitigation, orthogonal-projection deconfliction) — establish PROCEDURAL fixes (project away/orthogonalize conflicting gradients) for cross-task interference during joint optimization, not a diagnostic/certificate for when tasks are naturally separable — distance: medium — addresses the same phenomenon (off-block coupling) but treats it as something to remove online rather than something to measure/certify/discover a representation for; no Fisher/excitation-Gram formalism, no identifiability proof, no RL-Hankel unification.
- Martens & Grosse 2015 (K-FAC) and its 2024-2025 descendants (mini-block Fisher, SK-FAC, EVA, unit-wise block-diagonal-Fisher approximation theorems) — establish block-diagonal (Kronecker-factored) approximations of the Fisher matrix as a COMPUTE/optimization-tractability device, with theorems showing the approximation error (off-diagonal-block mass) is small under certain conditions — distance: far-to-medium — same literal linear-algebra object (block-diagonal Fisher, and even an 'off-block mass is small' theorem analogous to the note's ρ), but purposed entirely differently: an approximation for natural-gradient computation, not a certificate of skill/task identifiability, separability, or reward-decomposition, and never proposed as a discovery/training target for representations.
- Machado, Bellemare & Bowling 2017 (Laplacian eigenoptions) and Eysenbach, Gupta, Ibarz & Levine 2019 (DIAYN) — establish skill/option discovery via, respectively, spectral decomposition of the state-transition graph Laplacian and a mutual-information/diversity objective — distance: medium — same end goal (decompose a task into separately useful skills) but a demonstrably different discovery SIGNAL (graph connectivity / diversity, not excitation-Fisher of value features), with no identifiability certificate and no per-block PE-rate guarantee; the note itself correctly identifies these as the comparison/kill-test (prediction 4, section 8) rather than a subsuming threat, and that self-assessment holds up under this search — no neighbor found that reframes eigenoptions/DIAYN in excitation-Gram terms.

- Wiedemer, Mayilvahanan, Brendel & Bethge 2023 (Compositional Generalization from First Principles) — gives sufficient conditions (support structure / compositional generative process, additivity) under which models provably generalize compositionally to unseen factor combinations — distance: medium — conceptually adjacent to the note's 'skills recombine ⟹ football objective' claim, but the operative condition is a compositional-support/additivity condition on the generative process, not an excitation/Fisher-Gram block-diagonality certificate, and it has no RL/PE/reward-decomposition content.
- 'A theoretical model for task routing in mixture-of-expert transformers' (arXiv 2606.14398, 2025-26) — proves MoE routing provably modularizes computation for latent cluster-structured tasks with reduced sample complexity vs. dense networks — distance: medium-far — a different mechanism (learned discrete routing/clustering of experts) achieving a related outcome (independent per-cluster computation), no excitation/Fisher/PE vocabulary, no identifiability certificate of the note's form, no RL-Hankel unification.

**Subsumption threats:**

### Developer formulation
**Object definition:** Let x ~ mu be the activation stream at a fixed site (e.g. residual stream, layer L) over a corpus. An SAE at that site has encoder rows w_j ∈ R^d, biases b_j, decoder columns d_j ∈ R^d (j=1..m, m>d, overcomplete), with z_j(x) = ReLU(w_j^T x + b_j). Firing region S_j = {x : w_j^T x + b_j > 0}, firing frequency f_j = P_mu(S_j).

Per-feature excitation (Gram), CONDITIONAL on firing (this normalization is essential — the unconditional version E[xx^T 1_{S_j}] confounds excitation with frequency by construction):
  G_j := E_mu[ x x^T | S_j ] ∈ R^{d×d},  alpha_j := lambda_min(G_j).
Residualized (splitting-sensitive) variant: let N_j = {k≠j : corr(z_j,z_k) > tau} (co-active neighbors); Π_j^perp projects onto span{d_k : k∈N_j}^⊥; G_j^perp := E[Π_j^perp x x^T Π_j^perp | S_j], alpha_j^perp := lambda_min restricted to a fixed shared low-rank subspace (to avoid finite-sample rank deficiency artifacts when f_j is small relative to d — this restriction/regularization is a required, not optional, implementation detail).

Identifiability of feature j means: statistical/estimation identifiability — the SAE training procedure's recovered (w_j,d_j) is reproducible (low variance) across resamplings of training randomness (seed / data order / dataset) — NOT recovery of an assumed ground-truth generative dictionary (no such ground truth is established to exist for real LLM activations). This is local (a statement about isolatedness of one training optimum via a Gauss-Newton/Gram proxy for local curvature on the ReLU-active set, valid only if the L1 penalty contributes zero curvature there, which holds because the L1 term is linear in z_j on the active set but has not been separately verified against the true training Hessian) and defined up to: (i) permutation of feature indices, (ii) scale (fixed by the SAE's own unit-decoder-norm convention), (iii) rotation within any degenerate (near-zero-eigenvalue) subspace of G_j shared with another feature — condition (iii) is the exact algebraic signature of feature splitting.

**Core claims:**
- (a-object) The per-feature excitation of SAE feature j is the activity-conditioned second-moment of the input stream: G_j = E[x x^T | S_j] where S_j = {x : w_j^T x + b_j > 0} is feature j's ReLU firing region (w_j = encoder row, x = activations at the chosen site). The frequency-normalized diagnostic is alpha_j = lambda_min(G_j) — the conditional Gram's smallest eigenvalue, NOT the unconditional (frequency-scaled) E[xx^T·1_{S_j}], which trivially tracks firing rate. A residualized variant G_j^perp projects x onto the orthogonal complement of decoder directions of features k that co-fire with j above a correlation threshold, isolating information uniquely attributable to feature j (this is the object that should carry a feature-splitting signature: two split siblings share S_j and a near-degenerate joint eigenspace).
- (a-identifiability) 'Identifiable' here must mean estimator reproducibility (an M-estimator/statistical-identifiability claim: low variance of the recovered (w_j,d_j) across resamplings of training randomness — seed, data order, dataset), NOT recovery of a pre-existing ground-truth generative feature, since no independently-defined ground truth dictionary for LLM activations is known to exist. This reframing is required to avoid a category error at the gate ('identifiable relative to what truth?'). Under this reading, alpha_j>0 on the ReLU-active set is exactly a local, per-atom analog of the incoherence/sample-richness conditions used for local recovery in overcomplete sparse dictionary learning (Spielman-Wang-Wright 2012; Arora-Ge-Moitra 2014; Agarwal-Anandkumar-Netrapalli), restricted to the observed (non-generative-model-assumed) activation stream rather than assumed under a planted-dictionary model — this is the actual novelty wedge: an empirically computable, assumption-light diagnostic versus an existence-guarantee-under-generative-model theorem. Identifiability is explicitly local (isolatedness of the training optimum, not global uniqueness of the whole m-atom dictionary, which is a much harder, generally intractable claim) and up to permutation/scale plus rotation within any near-zero eigenspace of G_j shared with a near-duplicate feature (this IS the algebraic signature of feature splitting).
- (b-diagnostic) alpha_j (or the residualized/normalized version) predicts cross-seed / cross-width / cross-checkpoint instability of feature j, and — critically — this predictive power must survive controlling for raw firing frequency f_j = P(S_j), since G_j's trace trivially scales with f_j. The correct test is a partial-correlation or frequency-stratified comparison of alpha_j (conditional, not joint, Gram) against a matched stability metric, not a raw unconditional correlation.
- (c-repair) A concurrent-learning-style buffer that stores, per feature j, a bounded set of exemplars from S_j selected to maximize lambda_min(G_j) (Chowdhary & Johnson's stored-exciting-data-point mechanism, direct transplant), replayed during SAE training, yields higher post-training alpha_j and higher cross-seed feature-matching stability than (i) a no-buffer control and (ii) a frequency-matched but non-excitation-curated replay buffer of equal size, at equal total compute/data budget. This is the third instantiation in the program of the same concurrent-learning-replay primitive (after A5 for ICL demos and C4/G6 for RL trajectories); its only novel content is the SAE-training transplant, and its fate should be checked for consistency with how A5/C4 fare, not treated as an independent bet.
- (prior-art risk) The per-feature conditional Gram is structurally the same object TYPE as A1's static-face lambda_min(P^T M_S P), which track-status.md records as having failed its own gate ('wrong-object + circular', corrected to an information quantity J(S) equivalent to Merhav-Feder/van Trees). E1 must show explicitly why S_j's self-referential conditioning (S_j is defined by the very feature being tested) does not reproduce that circularity before it can be presented as well-defined.

**Falsifiable predictions:**
- P1 (variance link, survives frequency control): across features at fixed layer/site, a cross-run instability metric (e.g. 1 minus best-match decoder cosine similarity across two independently seeded/trained SAEs, or across an SAE trained on two data splits) is a monotone decreasing function of alpha_j / alpha_j^perp, and this relationship remains statistically significant after partialling out log(f_j) — i.e. within frequency-matched bins, low-alpha_j features are still more unstable than high-alpha_j features at the same frequency.
- P2 (splitting signature, testable on Gemma Scope width sweeps with zero training): among features of a narrower Gemma Scope SAE (fixed layer/site, width w1), those with low alpha_j^perp are preferentially the ones that decoder-cosine-match to ≥2 features in a wider SAE at the same site (width w2>w1), at a rate exceeding the frequency-matched base split-rate.
- P3 (repair, requires training): SAEs trained with a per-feature lambda_min-maximizing concurrent-learning replay buffer show, at equal total compute and equal total (unique+replay) data budget, higher post-training alpha_j for previously-low-alpha_j features AND higher cross-seed matching stability than both (i) a no-buffer control and (ii) a frequency-matched-but-not-excitation-curated replay control of identical buffer size.

**Kill criteria:**
- K1 (the pre-registered central kill criterion): if the partial correlation of instability with alpha_j (or alpha_j^perp), controlling for log(f_j), is not significantly different from zero — equivalently, if a frequency-only predictor achieves equal or better AUC/R^2 for instability than alpha_j does — claim (b) is dead: it reduces to the already-known trivial fact that rare features are less pinned down, adding nothing.
- K2 (disconnection from the target phenomenon): if low alpha_j^perp does not predict which narrow-dictionary features split into multiple wide-dictionary features on Gemma Scope width sweeps at above the frequency-matched base rate, E1 has failed to connect to the flagship SAE reliability failure (feature splitting) it is pitched to explain, and demotes to an unconnected curiosity.
- K3 (repair collapses to known trick): if curated (lambda_min-maximizing) buffer selection does not outperform a frequency/rarity-matched random-replay buffer of equal size at equal compute, claim (c) collapses to ordinary importance-weighted resampling of rare features — a known technique — and the concurrent-learning/PoE framing contributes nothing beyond relabeling it.
- K4 (wrong theoretical object): if the true training-loss Hessian restricted to (w_j,d_j) on the active set is not well-approximated by G_j (e.g., because the L1-penalty's contribution to curvature at the ReLU boundary, or interaction terms with co-active features, dominates), then lambda_min(G_j) is not the right local-identifiability functional and the object must be replaced by the actual (residualized) Gauss-Newton/Hessian block before any of (a)-(c) can be trusted.
- K5 (circularity recurrence — the specific internal precedent): if the S_j-conditional Gram construction reproduces the same 'wrong-object + circular' failure that track-status.md records for A1's static-face lambda_min(P^T M_S P) (self-referential conditioning on a set defined by the very quantity being estimated), E1's object as stated is not well-defined and requires the same information-theoretic (J(S)-style, Merhav-Feder/van Trees) correction A1 received before it can pass a theory gate.

**Open risks:**
- No independently-defined ground-truth feature exists for real LLM activations (unlike classical PoE's known-true-parameter setting); 'identifiability' must be explicitly reframed as estimator-reproducibility (an M-estimator stability claim) rather than ground-truth recovery, or the object commits a category error at the gate. This reframing is necessary but changes what is being claimed relative to the classical PoE literature cited as backing.
- Finite-sample rank deficiency: for rare features (small f_j) in high ambient dimension d, G_j is generically near-singular purely from sample-size scarcity within S_j, independent of any true excitation deficiency — alpha_j must be computed on a fixed, shared low-rank subspace or with a matched-sample-size null model, or the diagnostic is contaminated by an artifact that looks exactly like the frequency confound K1 is meant to rule out.
- Public multi-seed SAE suites may not exist for Gemma Scope (it appears to be single-seed-per-configuration with a width/sparsity sweep); P2/K2 (splitting via width sweep) are achievable with zero training, but P1/K1 (seed instability) likely require training a modest number of additional SAEs — cheap relative to the base LM but not strictly 'without training anything' as specified in the task; this is a real scope reduction from the stated diagnostic claim.
- Prior-art risk specific to claim (b): Paulo & Belrose (2025, 'SAEs trained on the same data learn different features') is the closest existing empirical treatment of SAE seed instability and may already use a curvature/flatness-based predictor that is mathematically equivalent to lambda_min(G_j); this needs an explicit literature check before the gate, since it is the single most likely piece of prior art to preempt (b) as merely a renaming.
- The residualization defining G_j^perp (which co-active features count as 'neighbors', what correlation threshold tau) introduces a design choice that, if tuned after seeing results, could manufacture the splitting signature in P2/K2 post hoc; tau and the neighbor-selection rule must be pre-registered before testing against Gemma Scope.
- Mechanism reuse across the program: claim (c) is the third application of the identical concurrent-learning curated-replay primitive (A5 for ICL demonstrations, C4/G6 for RL trajectories, now E1 for SAE features). None of the three has been gated. If A5 or C4 are gated first and found to collapse to simple importance-resampling baselines (the K3 failure mode), that is directly informative evidence against (c) surviving its own gate and should be tracked as a single cross-cutting bet on the transplant, not three independent ones.

### Prior art
**Nearest neighbors:**
- Taming Polysemanticity in LLMs: Provable Feature Recovery via Sparse Autoencoders, arXiv:2506.14002 (2025) — establishes a formal recovery/identifiability guarantee for SAEs via a 'bias adaptation' training algorithm, provable when the data-generating model satisfies a statistical richness condition requiring each latent feature to be activated ('excited') with sufficient frequency and combinatorial variety across the training corpus. Distance: CLOSE. This is the single strongest hit against the 'identifiability via excitation' half of E1: it already ports a PE-style richness-of-activation condition to the exact object (SAE dictionaries on LLM activations) and states it as a formal theorem, not a heuristic. Caveat: my reading of the exact theorem wording came via a secondhand summary of the PDF, not a verified direct quote of the theorem statement — needs firsthand confirmation before treating as a full kill. What it does NOT do: it is a static/batch guarantee (fixed corpus, i.i.d. statistical model) with no online/streaming setting and no repair mechanism — if the richness condition fails for some feature, the paper offers no fix, no monitoring, and no concurrent-learning-style buffer.
- A Unified Theory of Sparse Dictionary Learning in Mechanistic Interpretability: Piecewise Biconvexity and Spurious Minima, arXiv:2512.05534 (~2026) — proves SDL/SAE training is a piecewise-biconvex problem with a characterized (non-identifiable) global solution set, explains feature splitting/absorption/dead-neurons as consequences, and introduces 'feature anchoring' as a repair that provably restores identifiability. Distance: CLOSE on the 'identifiability + repair' framing, but MEDIUM on mechanism. Verified by direct fetch: feature anchoring is a loss-regularization/architectural fix (constrains a subset of encoder/decoder columns to known reference directions via an added ||W-anchor||^2 penalty) — a landscape/parameter-space restriction, not a data-selection or replay-buffer mechanism, and its identifiability theorem (Thm 3.4) characterizes the zero-loss solution manifold, not a data-richness/coverage condition. So it covers 'SAE identifiability + a repair' as a territory but is a different object from 'excitation-condition + concurrent-learning data-buffer repair.'
- Spielman, Wang & Wright 2012 (ER-SpUD, exact recovery of sparsely-used dictionaries); Gribonval & Schnass local identifiability via l1-minimization; Sun, Qu & Wright 2015/2016 (complete dictionary recovery over the sphere, nonconvex geometry); Arora, Ge, Ma & Moitra 2015 (simple/efficient/neural sparse coding algorithms) — the classical dictionary-learning identifiability literature. Distance: MEDIUM-CLOSE as a genus. These papers are, in substance, already a decades-old theory of exactly what 'richness of the sample/coefficient stream' is needed to guarantee unique dictionary recovery (sample complexity bounds, sparse-random-support conditions, incoherence/spark conditions) — the natural static-batch ancestor of a PE-style excitation condition for dictionaries. They predate SAEs, are stated for i.i.d. random-support coefficient models rather than LLM activation streams, are purely batch/offline, and carry no online-repair or concurrent-learning component — so they are the deep theoretical backbone the E1 line would have to build on/distinguish itself from, not itself a hit on the SAE-specific or repair-specific claims.
- Chowdhary & Johnson 2010/2011 (concurrent learning for adaptive control without persistency of excitation) and its adaptive-control descendants (Integral Concurrent Learning, Parikh et al. 2019; Decentralized Concurrent Learning, 2024) — establishes that storing and concurrently reusing a recorded, linearly-independent/exciting dataset can substitute for a continuous PE requirement to guarantee parameter convergence. Distance: FAR from the SAE literature as searched. No paper was found that imports this concurrent-learning mechanism (a maintained, verifiably-exciting buffer of past data used for concurrent parameter updates with a convergence guarantee) into sparse-dictionary/SAE training. This is the one seed-list item that appears to remain genuinely un-ported to the ML-interpretability object — but note replay/coreset/experience-replay mechanisms are extremely common in adjacent ML subfields (continual learning, e.g. 'Provable Effects of Data Replay in Continual Learning: A Feature Learning Perspective', arXiv:2602.02767) without the PE/concurrent-learning theoretical framing attached, so the vocabulary gap may be larger than the substance gap.
- Paulo & Belrose 2025 (SAEs trained on the same data learn different features, arXiv:2501.16615); 'Unstable Features, Reproducible Subspaces: Understanding Seed Dependence in SAEs' (arXiv:2606.12138); Archetypal SAE (Fel et al., ICML 2025, arXiv:2502.12892) and its rebuttal 'Ablating Archetypes' (arXiv:2606.02061); 'Position: Mechanistic Interpretability Should Prioritize Feature Consistency in SAEs' (arXiv:2505.20254) — this cluster empirically documents and tries to fix non-identifiability/seed-instability of SAEs. Distance: MEDIUM. They establish the practical symptom E1 is meant to treat (SAE features are not reproducible/identifiable across seeds/runs) and propose fixes, but every fix found is either purely architectural (Archetypal SAE's convex-hull constraint on dictionary atoms), a measurement metric (PW-MCC), or post-hoc cross-run pooling (2606.12138) — none frame the cause as an excitation/richness-of-data deficiency or propose a concurrent-learning-style online data repair. Same symptom, different diagnosis and different fix vocabulary — adjacent territory, not the same object.
- 'Distribution-Aware Feature Selection for SAEs' / Sampled-SAE (arXiv:2508.21324) — title strongly suggested a match ('distribution-aware... identifiability challenges... information-theoretic... maximize signal-to-noise for sparse features'), but a verified direct fetch of the actual abstract showed it is a within-batch BatchTopK-selection heuristic (choosing which tokens/features populate the top-K pool per batch) with no identifiability theorem and no reference to PE, richness, or coverage conditions. Distance: FAR despite surface-level title similarity — a genuine false positive that the earlier AI-search summary initially mis-described; flagged explicitly because this program's stated failure mode is exactly 'same territory but not same object,' and this is the mirror case: same words, different object.
- Kissane et al. 2024 ('SAEs are highly dataset dependent: a case study on the refusal direction') — documents empirically that SAE features/directions change substantially depending on which dataset trains the SAE. Distance: MEDIUM. This is direct empirical evidence FOR the premise that data composition governs SAE identifiability (motivating E1), but it is diagnostic only — no excitation-style formal condition, no repair proposed.
- Hyvarinen & Morioka nonlinear ICA; Khemakhem, Kingma, Monti & Hyvarinen 2020 (iVAE) — establishes identifiability of nonlinear latent-variable/ICA models via auxiliary conditioning variables (non-stationarity, class/domain/time index) making the source distribution identifiable up to trivial indeterminacies. Distance: MEDIUM-FAR. Different formal object (continuous latent ICA/VAE models with auxiliary-variable conditioning) rather than sparse/overcomplete dictionary recovery with excitation-frequency conditions, but establishes the same general principle — 'sufficiently diverse/rich conditioning data is what buys identifiability' — in a cognate but distinct sub-literature; useful precedent, not a hit.

**Subsumption threats:**
- If arXiv:2506.14002's theorem is confirmed (on direct read) to state an explicit per-feature activation-frequency/richness condition as necessary-and-sufficient for SAE recovery, the 'identifiability via excitation' theoretical half of E1 is already published for the exact SAE object — E1 would only survive as the ONLINE/REPAIR half, not as a new identifiability theorem.
- The classical dictionary-learning identifiability literature (Spielman-Wang-Wright, Gribonval-Schnass, Sun-Qu-Wright, Arora-Ge-Ma-Moitra) already IS a mature theory of exactly what data-richness (sample complexity, sparse-random-support, incoherence) buys unique recovery; if E1's contribution is 'apply PE-style language to re-derive/restate these conditions for SAEs,' that could be judged a relabeling of 45+ years of dictionary-learning + PE theory rather than new mathematics, unless the SAE-specific nonlinearity (ReLU/TopK, superposition, non-stationary LLM activation streams) genuinely breaks the classical assumptions in a way that requires new theorems.
- arXiv:2512.05534's 'feature anchoring' already demonstrates that (a) SAE non-identifiability can be formally characterized and (b) a concrete repair technique that provably restores identifiability exists and is published (ICML/2026-era). Even though its repair mechanism differs (architectural anchoring vs. data-buffer concurrent learning), a reviewer could argue the 'identifiability + repair for SAEs' PROBLEM has already been solved-in-kind, making a second repair mechanism a incremental variant rather than a new problem class — especially if concurrent-learning-style repair turns out to be provably equivalent or dominated by anchoring in practice.
- Continual-learning replay/coreset theory (e.g. 'Provable Effects of Data Replay in Continual Learning: A Feature Learning Perspective', arXiv:2602.02767, and gradient-based sample selection for online continual learning) already provides theoretical treatments of WHY storing/replaying a curated subset of past data helps feature learning; if this body of work is shown to already cover the 'concurrent-learning repair' mechanism in substance (even without PE/Chowdhary-Johnson vocabulary), the E1 contribution shrinks to a vocabulary translation exercise.
- The field is moving very fast: at least 4-5 directly-competing SAE-identifiability theory papers surfaced with arXiv IDs in the 2505-2606 range (roughly May 2025-June 2026), i.e., published in the ~14 months before this investigation. This base rate suggests a nontrivial chance that a paper combining excitation-style identifiability AND an online/replay-based repair for SAEs specifically already exists in a corner of this fast-moving space not surfaced by these search queries (e.g., under different terminology such as 'active data curation for SAE training' or 'online SAE identifiability').
- Search results were obtained largely via AI-generated summaries of abstracts/PDFs rather than fully independently verified full-text reads of every theorem; there is a real risk that the summarizer over/under-stated a paper's actual scope (this already happened once with arXiv:2508.21324, where the initial WebSearch summary falsely suggested an identifiability theorem that a direct fetch of the abstract disproved) — the same risk applies to 2506.14002's 'excitation frequency' framing, which should be verified against the primary source before being treated as fully confirmed.

**Charges:**
- circular (unresolved, not merely risked): The object G_j = E[xx^T | S_j] conditions on S_j = {x : w_j^T x + b_j > 0}, a set defined by w_j — the very encoder direction whose identifiability is under test. The filing's only defense (open_risks / prior-art-risk item, K5) is to reframe 'identifiable' as estimator-reproducibility rather than ground-truth recovery. But that reframing answers a DIFFERENT objection (category error re: 'truth') than the one it's deployed against (self-referential conditioning set). Reframing away the ground-truth question does nothing to establish that conditioning the richness measure on a region carved out by an untrained/poorly-determined w_j tells you anything about w_j's identifiability, rather than just reflecting an accident of w_j's current position — which is exactly the shape of the failure track-status.md records for A1's lambda_min(P^T M_S P) (conditioning on a set defined by the object under estimation). E1 promises to 'show explicitly why S_j's self-referential conditioning does not reproduce that circularity' (its own stated pre-condition for being well-defined) but the filing never actually performs that demonstration — it substitutes the ground-truth reframing and calls the box checked. A1's actual fix was to replace the conditional Gram with an unconditional information quantity J(S) (Merhav-Feder/van Trees) that does not presuppose a running estimate of the tested direction as the conditioning variable; E1 has no analogous construction. As stated, the object is not shown well-defined.
- wrong-object (Hessian mismatch, K4, admitted but unresolved): the filing itself flags that G_j is only a valid local-curvature proxy 'if the L1 penalty contributes zero curvature on the active set... has not been separately verified against the true training Hessian' — an admitted, load-bearing, unverified assumption. Worse, SAE reconstruction loss couples (w_j,d_j) to EVERY co-active feature k through the shared residual x_hat = sum_k z_k d_k, not just to features above the correlation threshold tau used to build G_j^perp. Superposition — many features weakly co-active, few strongly correlated pairs — is the defining regime SAEs are built for; the tau-thresholded residualization therefore excludes exactly the interaction term (diffuse cross-feature reconstruction coupling) that the superposition literature identifies as central, not a corner case. G_j is likely a systematically wrong Hessian proxy in precisely the regime the method is meant to operate in.
- wrong-object (P2/K2 specificity, splitting vs. geometric coincidence): a near-degenerate eigenspace of a half-space-conditioned Gram G_j (or G_j^perp) is, generically, a property of local activation-manifold geometry near S_j, shared by ANY features whose firing half-spaces happen to be similarly shaped/oriented — not something special to true split siblings (features that are semantically near-duplicates). G_j^perp only projects out decoder directions of DECODER-correlated co-active neighbors (corr(z_j,z_k) > tau); it does nothing to exclude unrelated features k that merely fire on geometrically similar regions of activation space without co-activating or being decoder-correlated — a common occurrence given that activations cluster by topic/token-position along shared axes. Such pairs would trip P2's positive-condition (shared near-zero eigenspace) despite not being splits, and a high match rate could equally be read as confirming the splitting-signature theory or as an artifact of generic regional geometry — the test as specified cannot cleanly separate the two, contaminating K2 in both directions.
- subsumed (identifiability half): the prior-art filing surfaces arXiv:2506.14002 ('Taming Polysemanticity... Provable Feature Recovery via Sparse Autoencoders') as CLOSE — a formal recovery/identifiability theorem for SAEs conditioned on a per-feature activation-frequency-and-variety richness condition, stated for the exact SAE-on-LLM-activations object, not a generic planted-dictionary model. If confirmed on direct read (flagged by the investigator as not yet independently verified beyond a secondhand summary), this already occupies the 'identifiability via excitation-style richness, for SAEs specifically' territory E1 claims as its novelty wedge in (a-identifiability) ('an empirically computable, assumption-light diagnostic versus an existence-guarantee-under-generative-model theorem' — but 2506.14002 is apparently exactly a theorem for the non-generative, actual SAE object, undercutting that distinction). This would leave, at best, only the online/repair half as potentially novel.

This is a strictly MORE COMPLETE result than E1's local lambda_min(G_j) heuristic: an exact global characterization of the failure mode versus a local curvature proxy of unverified fidelity (see wrong-object charge above), plus a repair with a convergence/restoration proof versus E1's untested data-buffer repair with no proof offered. ### Developer formulation
**Object definition:** Let Θ⊆ℝ^p be a task-parameter space (in controlled Garg-style ICL: an explicit generative parameter, e.g. regression weights, decision-tree structure, sparse support, sinusoid frequency/phase — genuinely nonlinear families already used in the cited ICL literature). Let h(x;θ) be the demo-response map (task's true output, or the model's induced output, for input x under task θ). For a demo set S={x_1,...,x_k}, define the response map Φ_S:Θ→ℝ^k, θ↦(h(x_1;θ),...,h(x_k;θ)), and its Jacobian J_S(θ)=D_θΦ_S(θ)∈ℝ^{k×p}.

STATIC FACE (B3). θ is LOCALLY WEAKLY OBSERVABLE from S at θ iff rank J_S(θ)=p — the driftless special case of the Hermann-Krener rank condition (no vector field/flow acts on θ, so the observability codistribution collapses to span{dh(x_i;·)}_i with no higher Lie-derivative terms needed; this is a deliberate correction of a naive 'Lie-derivative tower' framing, which does not apply absent dynamics). Diagnostic: failure on θ_true is predicted by (first-order proxy) 1/σ_min(J_S(θ_true)), interpreted as local distance to V_S via the implicit function theorem — an approximation valid near θ_true, not a global variety-distance claim.

B7 (adjacent). The DEFECTIVE LOCUS is D_S={θ∈Θ : rank J_S(θ)<p}, varying S with θ_true fixed. It already performs the exact fusion B3 wants ('unobservable variety' + persistency-of-excitation ⇒ nonlinear identifiability) — but the object is edge-additive multi-agent dynamical networks / DAGs (recovering unknown edge functions from node measurements), not neural-network training or ICL. Same theorem-template, different system class; the 'new' content shrinks to instantiating this template on a transformer/ICL system, which is a nontrivial but narrow transplant, not a new object.
- STRIKE-GOLDD / StrikePy (Villaverde et al., FISPO algorithm, actively maintained Python/Maple tool through 2022-2025) and SIAN / DAISY — mature, off-the-shelf software that computes exactly the local structural-identifiability-and-observability rank condition B3 proposes as a 'diagnostic,' for general nonlinear ODE models. Distance: close-medium. Kills the 'build a new observability-index tool' framing outright — the computational machinery already exists and is turnkey; it has just not been pointed at ICL/transformer objects (which itself requires nontrivially casting attention/context dynamics as a state-space model with unknown 'parameters' to test).
- 'On the importance of structural identifiability for ML with partially observed dynamical systems' (arXiv:2502.04131, 2025) — explicitly connects structural (un)identifiability of a latent dynamical model to downstream ML classifier performance and proposes a fix (Structural Identifiability Mapping). Distance: medium-close. This is precisely the move 'observability/identifiability diagnostic predicts/explains ML performance,' but for SVM classifiers on parametrized-ODE latent states, not transformers/ICL, and it does not build an 'index' or touch ordering/curriculum.
- Observable Neural ODEs for Identifiable Causal Forecasting (arXiv:2604.26070, 2026) — parameterizes latent Neural ODE dynamics in observable normal form so that observability (hence causal identifiability) holds by construction. Distance: medium. Shows the observability-for-neural-nets fusion is a live 2026 research direction, but as an architectural constraint for causal forecasting, not a post-hoc diagnostic for ICL/few-shot, and not an ordering/curriculum result.
- Sussmann 1992 / Fefferman & Markel 1993 (classical) and modern descendants (e.g. 'Most ReLU Networks Admit Identifiable Parameters,' arXiv:2605.03601, 2026; 'Symmetry in Neural Network Parameter Spaces,' 2025) — establish neural-network parameter identifiability up to permutation/sign-flip symmetry via algebraic/functional-equivalence arguments, NOT via differential observability rank conditions. Distance: medium/far. Answers a cousin question ('can weights be recovered from the I/O map') with a different formal apparatus; crowds the 'NN identifiability' niche generally but does not use or compete with the observability-index vocabulary specifically.
- Lu et al. 2022, 'Fantastically Ordered Prompts and Where to Find Them' — CLOSE THREAT for B4. Establishes that ICL accuracy is highly order-sensitive (±15% swings from permutation alone) and that this is a general, model-existing phenomenon; proposes probing-set entropy metrics (GlobalE/LocalE) as a cheap, label-light score that predicts good orderings and is used to select order. Distance: close. This already delivers B4's core empirical claim and a working diagnostic score, ~4 years before this line, with thousands of citations and an active descendant literature.
- 'What Makes a Good Order of Examples in ICL' (ACL Findings 2024) and 'Hierarchical Demonstration Order Optimization for Many-shot ICL' (NeurIPS 2025) — direct, recent (2024-2025) extensions of the demo-ordering-optimization space with new metrics (hierarchical/coverage-based). Distance: close. Shows the exact niche B4 aims at is being actively mined right now using non-control-theoretic tools; B3/B4's judge-crash in this program left this territory unclaimed by us while the field kept publishing in it.
- Uniform complete observability, Kalman (1960s) / Anderson & Moore — classical result that a linear time-varying system is uniformly completely observable iff the observability Gramian over a sliding finite window is bounded above and below uniformly in the start time; underwrites Kalman-filter convergence independent of the specific window chosen. Distance: medium-far for B4's specific claim. Gives the general mathematical shape ('windowed/ordered observability, not just cumulative observability, matters and has a uniform-bound criterion') that B4 wants to invoke for demo/curriculum ordering, but it is about known linear time-varying dynamics with a continuous/discrete time index, not about ordering a finite set of discrete training examples or ICL demos for a learned nonlinear model. No paper found makes this transplant; it is the one place daylight plausibly exists, contingent on constructing a rigorous mapping (demo-subsequence-window ↔ Gramian window) rather than just an analogy.
- Curriculum learning literature (Bengio et al. 2009 canonical source; modern surveys and 2025-2026 instances: 'Curriculum Learning for LLM Pretraining,' 'Fisher Information-based Efficient Curriculum Federated Learning' EMNLP 2024, 'The Order Is The Message' arXiv:2603.25047 2026) — broad empirical/heuristic literature (including a Fisher-information-scored curriculum variant already) establishing order/curriculum effects on training dynamics via difficulty-, loss-, perplexity-, or Fisher-based scores. Distance: medium. None found ground ordering in an observability/PE-theoretic argument for *why* an order is optimal (vs. empirical difficulty heuristics), which is the one place B4 could differentiate itself — but it must then beat these active, well-resourced heuristic baselines empirically, which is untested.
- Online active-learning excitation design for nonlinear system ID (arXiv:2506.21754, 2025) — uses active-learning-selected excitation inputs at runtime, coupled to a Kalman filter, for nonlinear system identification; directly instantiates 'PE-optimal adaptive ordering/selection of excitation' in a 2025 ML-adjacent setting. Distance: medium. Same mechanism family as B4 (adaptive excitation selection ⇒ better identification), but for classical dynamical-system parameter estimation, not transformer/ICL/curriculum objects.
- Amendola, Ranestad, Sturmfels et al. — algebraic-geometry (moment-variety / secant-variety) identifiability criteria for Gaussian mixtures. Distance: far. A structurally different rigorous apparatus for identifiability (algebraic geometry of moment tensors vs. differential-geometric observability), for static mixture models, not sequential/dynamical observability or ordering; relevant mainly as evidence the identifiability-diagnostic space is being attacked from multiple independent mathematical directions simultaneously, further crowding B3's niche.

**Subsumption threats:**
- B3's core theoretical claim (define an 'unobservable variety' and use a PE/excitation-style richness condition to certify identifiability of a nonlinear system) is already published almost verbatim in Vizuete & Hendrickx 2024 (arXiv:2405.07636) — same vocabulary ('unobservable variety'), same mechanism (excitation ⇒ identifiability), full necessary-and-sufficient theorem. If B3's contribution is the theorem template itself, it is subsumed; it survives only as 'apply this template to a new system class (NN/ICL forward maps),' which must then be shown to be a nontrivial instantiation (attention/context is not obviously a state-space system with the additive-edge-dynamics structure the theorem assumes).
- B3's proposed 'diagnostic tool' is already implemented and mature as software: STRIKE-GOLDD/StrikePy (FISPO), SIAN, DAISY compute exactly the local structural-identifiability/observability rank condition for general nonlinear (ODE) models, actively maintained through 2022-2025. Unless B3 needs genuinely new machinery (not just a new application domain), the 'build a diagnostic' framing is fully subsumed at the tooling level.
- B4's core empirical claim (demonstration order matters for ICL and a cheap computable score predicts good orderings) is already established and actively extended: Lu et al. 2022 (GlobalE/LocalE entropy metrics, ±15% swings from order alone) through ACL-Findings-2024 and NeurIPS-2025 hierarchical order-optimization papers. If B4's only distinguishing feature is 'we use observability theory instead of entropy,' the empirical territory (order sensitivity + a predictive diagnostic) is already fully occupied; the wedge narrows to a mechanism/vocabulary difference that has not been shown to produce different or better predictions.
- The 'uniform observability ⇒ optimal ordering/curriculum' bridge that would make B4 genuinely new (mapping Kalman/Anderson-Moore uniform-complete-observability-window theory onto discrete demo/curriculum ordering) was not found anywhere in the literature searched — meaning either (a) it is unclaimed territory, or (b) it is unclaimed because the transplant doesn't actually work / isn't a meaningful generalization once attempted (the same failure mode that killed A1's original λ_min(P^T M_S P) claim and B8's block-Hankel line in this same program). Given the program's track record of PE-transplant claims dissolving under formal scrutiny, this must be treated as a live threat, not assumed to be daylight, until worked through.
- Both B3 and B4 were dropped in this program purely because judging agents crashed (StructuredOutput failure), not because of any substantive critique — meaning no adversarial gate has yet stress-tested whether the 'apply classical nonlinear-observability/uniform-observability theory to ML' move survives contact with the same rigor that demoted A1 (static face doesn't inherit PE; 'same territory ≠ same object' cuts both ways) and B8 (sound but classical, no new functional). There is a real risk B3/B4 would independently re-derive that verdict: classical control theory transplanted into ML vocabulary, subsumed by existing ML-native diagnostics (entropy-based ordering scores, structural-identifiability-for-classifiers) that already do the practical job without the control-theoretic apparatus.

**Residual novelty:** If every threat above holds at its strongest reading, what survives is narrow: (1) for B3, a genuine but unproven instantiation gap — nobody has cast a trained transformer's few-shot/ICL forward map (or an attention-based sequence-to-output map) explicitly as a nonlinear state-space system and run the Hermann-Krener rank condition / STRIKE-GOLDD-style FISPO analysis on it to get an 'unobservable variety' over task-relevant latent directions; this is a real, currently-undone application, but it is application-of-known-machinery, not new theory, and its value depends entirely on whether the resulting diagnostic beats or explains something existing ICL diagnostics (Spearhead A's λ_min-based instrument, or entropy-based order scores) do not. (2) For B4, the specific bridge from *uniform complete observability of time-varying linear systems* (a windowed, uniform-in-time Gramian bound) to *demo/curriculum ordering* has not been made by anyone found, and it is a mechanistically different explanation than the entropy/coverage heuristics that currently dominate the ICL-ordering and curriculum-learning literatures — so IF it can be made rigorous and IF it produces orderings/predictions that diverge from and outperform GlobalE/LocalE-style and Fisher-curriculum baselines, there is a real wedge. But absent that rigor and that head-to-head comparison, both B3 and B4 currently read as re-labelings of active, well-resourced, already-productive research programs (nonlinear-network identifiability via excitation; ICL order-sensitivity diagnostics; Fisher/perplexity-based curricula) using older control-theoretic vocabulary — the same failure pattern this program has already found and killed twice (A1, B8). The honest verdict is: not yet subsumed on paper, but the theory-gate this line never received (the gate run was lost to a crash, not to critique) is very likely to reduce it the same way, and the burden is on demonstrating the instantiation is nontrivial and the observability-based ordering criterion is empirically distinct from existing entropy/Fisher-based ones — not on the novelty of the underlying control theory, which is 50 years old and already fused with PE (Vizuete-Hendrickx 2024) and already tooled (StrikePy/SIAN/DAISY).

### Prosecution
**Charges:**
- [subsumed / near-circular, strongest charge] B3's J_S(θ)=D_θΦ_S(θ) is very likely a resubmission of an object this exact program already tried and killed. track-status.md lines 13-16: A1's static face used λ_min(P^T M_S P), was found 'wrong-object + circular', was 'corrected to J(S)', and THAT corrected object was found 'subsumed by Merhav–Feder + van Trees.' - [wrong-object, compounding subsumption] Invoking Hermann & Krener 1977 ('driftless specialization') for a problem the filing itself insists has NO dynamics is decorative dressing on a much older, more directly on-point, and already-cited-by-the-program-itself result: Rothenberg 1971 ('Identification in Parametric Models', Econometrica) gives exactly the local-identifiability-via-Jacobian-rank condition for STATIC nonlinear parametric models — no drift, no vector field, no Lie derivative anywhere in its statement, because it was never framed as control theory. Reaching for Hermann-Krener and calling it a 'driftless specialization' manufactures an appearance of generalizing dynamical observability theory when the actually-applicable theory (Rothenberg / Fisher-information local identification) never had dynamics to strip out in the first place. This is compounded by the prior-art investigator's own closest hit, Vizuete & Hendrickx 2024, which already publishes the 'unobservable variety' + excitation-implies-identifiability theorem verbatim for a different system class. Two independent, older bodies of work already own this territory under its correct name; the control-theoretic relabeling adds no content and actively obscures which literature the claim must be benchmarked against.
- [wrong-object / internal contradiction, kills B4's explanatory wedge] B4 imports classical UNIFORM/INTERVAL observability (Anderson 1977; Jazwinski) — a theory whose entire content is about a state that EVOLVES via a known/estimable transition dynamics Φ(t,τ) through time, and whose 'uniform in time' requirement exists precisely because old information about a MOVING target can go stale, forcing every window to be individually informative. But B3, in the very same filing, insists θ is STATIC across the whole prefix ('θ is static... each demo is a distinct output channel rather than a time-evolved observation') — precisely to justify NOT needing Lie-derivative/dynamical machinery. No transition matrix A(t)/Φ(t,τ) for θ is ever defined; attention weights w_i^{(j)}(π) are substituted by analogy, not by a derived correspondence. For a target that never moves, once any single window achieves adequate rank there is no theoretical reason (from the cited theory) that later windows must ALSO be well-conditioned — 'uniform in time' has no work to do when there is no time-varying state to lose track of. So U(π)=min_j λ_min(Ω_j(π)) is not licensed by the theory the filing cites; it is an ad hoc windowed statistic wearing uniform-observability's name. This directly triggers B4's own kill criterion (mode-coverage explanation collapsing to 'recency bias with extra algebra'), since nothing in the actual mathematics distinguishes 'a window is uninformative because content is missing' from 'a window is uninformative because attention decays with position' absent the theory the filing claims justifies the distinction.

Any model whose ICL prediction is even loosely continuous/Lipschitz in the demo outputs it conditions on — true of essentially every trained sequence model, independent of whether it performs anything like observability-style computation — will show reduced discrimination on such pairs. Confirming B3-2 therefore does not discriminate the observability-theoretic mechanism from the much weaker, already-known null hypothesis 'the model is a smooth function of its inputs.' The proposed control (matched-distance pairs not near V_S) mitigates but does not eliminate this: it still only shows smoothness-in-outputs predicts confusability, not that the model is doing anything describable as Jacobian-rank identifiability.

This is a deeper problem than the filed open_risk's 'not autodiff-accessible, use a discrete surrogate' framing suggests: it threatens whether Φ_S(θ) is even a coherent function of θ for a fixed S outside the synthetic regime, not merely whether it's hard to differentiate. ### Defense
**Rebuttals:**
- Charge 1 overreaches by treating 'the kill criterion will likely trigger' as already-adjudicated death. The filing pre-registered exactly this risk as B3's own kill criterion before any test was run -- that is correct epistemic conduct, not a hidden flaw the prosecution discovered. A charge that the object 'is close to mathematically guaranteed' to fail its own honest, self-imposed test is not evidence of bad faith or of prior adjudication; it is a reason to run the test, and the filing already scopes B3's survival on doing so. The prosecution has not shown the variety-proximity claim (V_S, B3-2) or the rate-of-degradation claim (B7) are subsumed by J(S) -- only the point-level sigma_min diagnostic is threatened, and the filing itself flags that as the weakest, most J(S)-like part.
- Charge 3's 'internal contradiction' misreads the theory it cites. Anderson's own foundational work on persistency of excitation (Anderson 1977, and the broader Anderson-Johnson adaptive-identification line) is specifically about identifying a CONSTANT unknown parameter through a TIME-VARYING regressor/output map -- that is the canonical origin of 'persistency of excitation' in adaptive control, not a theory restricted to a state that itself evolves via known transition dynamics. A static theta observed through a sequence of attention-induced, prefix-dependent linear maps C_j(pi) is precisely the LTV-regressor-with-constant-parameter setting classical PE theory was built for; 'uniform in time' there means uniform-in-window informativeness of the regressor sequence, not tracking a moving target. The prosecution's characterization of the cited theory as requiring a moving state is not accurate to Anderson's PE papers specifically (as opposed to the Kalman-filter convergence literature more broadly), so B3's static-theta framing and B4's windowed-Gram framing are not in the contradiction the charge claims -- though the filing should make the C_j(pi) correspondence explicit and rigorous rather than asserted by loose analogy, which is a legitimate residual gap, not a logical inconsistency.
- Charge 5's conclusion that B7 is therefore valueless does not follow from its premise. That the measurement apparatus for the rate is reused from B3 does not make the predicted RELATIONSHIP (rate of sigma_min degradation predicting fragility better than the level does, on a held-out perturbation grid) trivially true or circular -- it is a distinct, falsifiable empirical claim that could fail even though it is computed by finite-differencing an existing instrument. Reduced novelty of machinery is conceded above; reduced novelty of the empirical prediction is not established by this charge.
- Charge 6 overstates its own force by eliding the object_definition's explicit primary scoping to 'controlled Garg-style ICL' with 'genuinely nonlinear families already used in the cited ICL literature' -- the strongest predictions (B3-1) are already confined to exactly the synthetic regime the charge says is required. The gap is real for B3-2's phrasing and for any claimed extension to real LLMs, which the open_risks section does flag (perhaps too lightly) as unresolved -- but this is an acknowledged scoping problem to be tightened at pre-registration, not a previously hidden defect discovered by the prosecution.
- Charge 7's 'either horn undercuts the wedge' framing sets up a false binary. The A1 gate's 'wrong-object' verdict on the raw, unprojected M_S was specific to a stronger claim (the self-referential fixed-point dilution law), not a general proof that raw content-based Grams carry zero order-predictive signal. B4's claim is weaker and more modest: that a raw, projection-free U(pi) beats recency-only heuristics and matches or beats Lu et al. at equal budget -- this does not require task-relevant projection to be non-vacuous, only to be better than positional bias alone, so the 'costs labels like Lu et al. or is wrong-object like A1' dichotomy is not exhaustive.
- Charge 9 is a real open engineering risk but is overstated as fatal. The Tier-A synthetic regime referenced elsewhere in this program's own notes permits k to be chosen freely (not capped at 'realistic few-shot' 4-32), and constructing near-equal-Gram, unequal-min-eigenvalue permutation families is a standard type of problem in combinatorial/blocked experimental design (balanced incomplete designs, Latin-square-style constructions) -- existence is plausible though unproven, and the honest posture is 'unproven construction, needs a worked existence argument before the empirical test is run,' matching what open_risks already says, not 'undemonstrable.'

This is a real citation/framing defect, though repairable (re-cite Rothenberg as the base case) rather than fatal to the underlying object.
- Charge 4 substantially lands: B3-2's confusability test, as specified, is not clearly distinguishable from the weaker null hypothesis that the model is a locally Lipschitz/smooth function of its conditioning outputs. The matched-theta-distance control does not close this gap, since output-space (Phi_S) closeness at fixed theta-distance is exactly what smoothness already predicts. B3-2 needs a sharper design to carry weight as evidence for an observability-specific mechanism.
- Charge 5 is correct that B7's proposed test is instrumentally identical to finite-differencing the B3 machinery -- it is not an independently constructed measurement device, and the filing's 'genuinely distinct, not a restatement' framing overstates the independence of the two kill criteria.
- Charge 6 is correct that the well-definedness gap for real (non-synthetic) models is deeper than the filing's open_risks entry admits, and B3-2 as worded is not explicitly restricted to the synthetic regime even though the object_definition's primary framing is controlled/Garg-style.
- Charge 7 is factually verified against fixed-point-poe-note.md line 151-152 ('P is not free. Estimating F_task needs a few labeled probes') -- there is a real, unaddressed tension between B4's 'no labeled probe set' selling point and the program's own prior admission that task-relevant projection costs labels.
- Charge 8 (unpinned window length N and layer/head aggregation for U(pi)) is correct as an additional degree of freedom beyond what the filing's pre-registration language currently covers; this should be pre-specified before any accuracy comparison.
- Charge 9's underlying concern is legitimate: no construction method for matched-terminal-Gram permutation sets is currently given, and open_risks understates this as merely 'nontrivial' rather than possibly infeasible at small realistic k.

**Strongest surviving claim:** B4's sequential-face claim survives the internal-contradiction charge on the merits: a static task parameter theta observed through a sequence of attention-induced, prefix-dependent linear output maps C_j(pi) is exactly the constant-parameter/time-varying-regressor setting that Anderson's persistency-of-excitation theory was originally built for (this is PE's canonical use case in adaptive control, not an analogy under strain), so U(pi) = min_j lambda_min(window Gram) is a theoretically licensed windowed-informativeness statistic, not an ad hoc heuristic wearing borrowed vocabulary. What has NOT survived, and must be conceded, is: (a) B3's point-level diagnostic sigma_min(J_S(theta_true)) is very likely identical in substance to the program's own already-subsumed J(S)/Fisher object, so B3 can only be defended going forward on its variety-proximity (V_S) and curvature content, which in turn requires a sharper B3-2 design than 'smoothness in Phi_S predicts confusability'; (b) B7 is not an independent trial of anything, only a finite-difference reuse of B3's instrument, so it should be marketed as an extension of B3 rather than a distinct second-order claim; and (c) B4's 'no labeled probe set' advantage over Lu et al. needs an explicit account of how a raw (unprojected) window Gram acquires enough task-relevance to be more than positional bias, plus a pinned window-length/head-aggregation protocol and a demonstrated (not merely asserted) matched-terminal-Gram permutation construction, before the empirical predictions (B4-1/B4-2/B4-3) are meaningful tests rather than post-hoc-fittable ones. The line survives the theory gate only in this narrowed form: B4's windowed-observability mechanism as a genuine, correctly-grounded (not contradictory) transplant of constant-parameter PE theory to attention-order, contingent on closing (a)-(c) before compute is spent -- not as originally filed with the point-level Jacobian diagnostic and the 'genuinely distinct' B7 claim intact.

**Assessment:** None of the four obligatory candidates, nor the two additional ones found, survives as a combined object that is more novel than the strongest single-line claims already on record (G's narrow externally-partitioned sequential-only TD-Gram certificate; E1's narrowed (a)/(b) claims; B4's windowed-order mechanism). Three distinct failure patterns recur and are worth naming explicitly because they show the cross-line blindness gap, once actually probed, mostly does NOT hide rescuable novelty here: (1) TYPE MISMATCH — G's formalism is strict (orthogonal projectors Π_i, ΣΠ_i=I, externally pre-given, acting on a PSD Gram M* with a specific output/discount structure); E1's SAE atoms (non-orthogonal, no y) and B3's task-parameter variety (different space, nonlinear h) do not satisfy these preconditions without inventing new structure neither source note supplies (candidates 1, 2, and own-candidate 6). Forcing the combination either produces a category error or requires open theoretical work not yet done by anyone in this program. (2) DOUBLE-TRANSPLANT, NOT NEW LAW — B4's windowed-order Gram and G's revived C3/C4 per-mode scheduling really are the same mathematical object (candidate 3 is the one combination that is genuinely well-formed), but stacking two independently-flagged 'known criterion, new venue' transplants does not clear this program's own explicit novelty bar, which rejects transplants regardless of execution quality or whether the specific instantiation is unclaimed (this is the exact language the B4 judge used to reject B4 alone). It also carries an unclosed, previously-flagged prior-art risk (prioritized experience replay / info-gain curriculum RL) that the audit noted was never checked for the C-wedges. (3) SAME-GENRE REINFORCEMENT — pairing B3 and E1 surfaces that both were independently reduced by their own judges to the identical classical local-curvature/Fisher-information-at-a-point template; this is evidence the two novelty-REJECTs are mutually consistent, not evidence of hidden combined novelty. (4) PROGRAM-MANAGEMENT CONVENIENCE, NOT AN OBJECT — reusing the Spearhead A harness across lines (candidate 4) is legitimate engineering reuse but is explicitly the kind of thing the task description distinguishes from a genuine cross-line object, and it carries a documented risk (already realized once, in A1/Spearhead A itself) of validating a simplified proxy while implying validation of the actual elaborate construct. Weighing this against the three gated lines' own strongest surviving claims: G's narrow sequential-only certificate, E1's narrowed (a)/(b) diagnostic, and B4's windowed mechanism are each real, if modest, and each already required for any of the cross-line objects above to even be well-formed — i.e. the cross-line objects are strictly downstream of (contingent on, and no stronger than) the single-line repairs, not independent sources of novelty.

**Recommendation:** Do not let any cross-line object outrank or substitute for the three single-line build items. None clears novelty on its own terms; the one well-formed combination (B4-windowed-order as G's per-mode replay/exploration scheduler) is legitimate but is an INSTRUMENT-level engineering extension contingent on both parents already being independently confirmed and pinned down (G's external partition instantiated on a real modular value function; B4's window-length/head-aggregation protocol closed) — file it as an optional follow-on task appended to G's build order, not as a fourth gate-worthy line, and require the still-unchecked prior-art search (prioritized experience replay, info-gain curriculum RL) before any novelty claim is made about it. The B3+E1 same-genre finding should be recorded as corroborating evidence for both existing novelty-REJECT verdicts, not pursued as a build item. The SAE-as-G-modes and B3-variety-as-G-boundary candidates should be explicitly logged as 'not currently constructible' (type mismatches requiring undone theoretical work) so a future agent doesn't re-propose them without first doing that foundational math. Net effect on build order: none of this changes the existing ranking recommendation (resurrect B3/B4 first at near-zero cost, ideate E1 second, gate G last and only on its narrow surviving object) — the cross-line hunt closes the meta-check's blindness gap but does not surface a candidate strong enough to reorder that queue.
